<product_requirements>
The goal is to build a native Android app for air quality monitoring.
**Core Features:**
1.  **Login/Signup:** User ID and password authentication.
2.  **Main Page:**
    *   Calculate AQI: Display sensor readings (MQ7, MQ-135, SHT4X+SGP40, PMSA0031 PM2.5, Pulse Oximeter) from ESP32, store with user, time, location.
    *   Record Cough: Activate mic, record cough, save to database with timestamp. Integrate ML (TensorFlow Lite suggested) for cough type, severity, diagnosis, and save diagnosis. A modal window for recording.
    *   Record Oxygen level: Input from pulse oximeter (connected to ESP32), display, and store with user, timestamp.
    *   AQI-based recommendations (Good, Moderate, Poor, Severe, Danger) with suggestions.
    *   Information on lung diseases associated with poor air quality.
3.  **Hamburger Menu Pages:**
    *   **About Page:** Details of device, sensors, AQI calculation, app/device functioning.
    *   **GPS-Heat Map Page:** API with Google Maps to display a heatmap of AQI values from various users, color-coded (Green: Good, Yellow: Moderate, Orange: Severe, Red: Danger).
    *   **Check History:** View past AQI readings.
    *   **Settings:** Control app functions, update ESP32 IP.
    *   **Profile:** Change profile, log out.

**Technical Decisions during trajectory:**
*   ESP32 connection via hardcoded manual IP.
*   Cough analysis ML: integrate an existing solution (TensorFlow Lite suggested).
*   Google Maps API: placeholder with instructions.
*   Database: Firebase Firestore.
*   Authentication: Simple username/password.
*   Development Priority: UI/UX with mock data and Backend APIs.
*   Image storage: Base64 format for all images.
*   ESP32 sensors: Changed from PM10 to PMSA0031-PM2.5, SHT4x+SGP40.
</product_requirements>

<key_technical_concepts>
-   **Mobile Development:** Expo (React Native, Expo Router for file-based routing).
-   **Backend:** FastAPI (Python), Firebase Firestore (replacing MongoDB), Uvicorn.
-   **State Management:** Zustand, @react-native-async-storage/async-storage.
-   **Hardware Integration:** ESP32 (Microcontroller), various sensors (MQ7, MQ-135, SHT4X+SGP40, PMSA0031 PM2.5, Pulse Oximeter).
-   **ML Integration:** TensorFlow Lite (suggested for cough analysis).
-   **Mapping:** react-native-maps (Google Maps integration).
-   **Networking:** Axios (HTTP client).
-   **Audio:** expo-av (for microphone recording).
</key_technical_concepts>
